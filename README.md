## 🏗️ About the Website

This repository contains the **official portfolio and landing page** for Silent Thunder Squad — a premium, animated single-page application that showcases our team, services, and projects.

The site is designed to feel like a **cinematic storytelling experience**, not just a portfolio. Every section transitions like a chapter, with scroll-driven animations, particle effects, and interactive 3D elements that respond to your cursor.

### ✨ Highlights

- 🎬 **Cinematic scroll experience** — Chapter-based storytelling with GSAP-powered animations
- 🌀 **Interactive 3D crystal** — Three.js icosahedron that tracks your mouse in the About section
- ⚡ **Particle field hero** — Dynamic canvas particle system behind the landing
- 🃏 **Spotlight team cards** — Grayscale-to-color reveal on hover with scan-line effects
- 📐 **Horizontal scroll gallery** — Projects section with scroll-hijacked horizontal scrolling
- 🔤 **Kinetic typography** — SplitType-powered character animations, rotating chars, and reveal text
- ⚡ **Thunder particles** — Custom interactive lightning-inspired particle field in the CTA
- 🧈 **Butter-smooth scrolling** — Lenis smooth scroll with proper ScrollTrigger sync
- ♿ **Accessibility-first** — `prefers-reduced-motion` respected, semantic HTML, ARIA labels
- 🔍 **SEO-optimized** — JSON-LD schemas, keyword-rich meta tags, noscript fallback, sitemap

## 🏃 Getting Started

### Prerequisites

- **Node.js** ≥ 18
- **npm** ≥ 9

### Installation

```bash
# Clone the repository
git clone https://github.com/SilentThunderSquad/Silent-Thunder-Squad.git
cd Silent-Thunder-Squad

# Install dependencies
npm install

# Start development server
npm run dev
```

The dev server starts at **`http://localhost:8080`**.

### Available Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start Vite dev server with HMR |
| `npm run build` | Build production bundle to `dist/` |
| `npm run preview` | Preview production build locally |
| `npm run lint` | Run ESLint across the codebase |
| `npm run test` | Run tests with Vitest |
| `npm run test:watch` | Run tests in watch mode |

## 🔍 SEO

The site is fully optimized for search engines:

- **4 JSON-LD schemas** — Organization, WebSite, ProfessionalService, FAQPage
- **Complete Open Graph** — Title, description, image, URL, locale
- **Twitter Cards** — Summary large image with all properties
- **Canonical URL** — Prevents duplicate content
- **XML Sitemap** — Auto-discoverable via robots.txt
- **Noscript fallback** — Full HTML content for crawlers that don't execute JS
- **Semantic HTML** — Proper heading hierarchy, ARIA labels, section IDs
- **Geo targeting** — `geo.region=IN`, `content-language=en-IN`
